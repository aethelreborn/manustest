# Aethel website

A static product, documentation, privacy, and terms site that ships with the mobile app repository.

## Preview locally

```bash
cd website
python3 -m http.server 4173
```

Open `http://localhost:4173` in a browser.

The Android download button points to the latest GitHub release for `aethelreborn/manustest`. Once an APK is attached to a GitHub release, the link becomes the public download path.
